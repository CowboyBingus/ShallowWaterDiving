# Shallow Water Diving

Shallow Water Diving now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Shallow Water Diving's C source is in
[`src/components/shallow_water_diving`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/shallow_water_diving).

The standalone Lua mod (v3.10.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/ShallowWaterDiving/tree/legacy) branch. Its releases and tags are unchanged.
