Shallow Water Diving - v3.8.1
Release for Steam build 25480438 / EXE 1.8.46015.0. Offline checks passed;
dives, the shallow-water correction and the depth slider were confirmed in live
play. v3.8.1 changes only this documentation; the mod is identical to v3.8.

Keeps a shallow-water dive airborne: during the dive your Helldiver uses the
standing water reference, so shallow water no longer cancels the leap. Landing
restores ordinary prone and water behavior; ordinary prone input is unchanged.
Dry ground and deeper water keep the game's normal behavior.

Maximum dive depth: with Mod Options Menu installed, MODS > SHALLOW WATER DIVING
> Max Dive Water Depth sets the deepest water a dive can start in, from 0.20
(about lower-shin depth, the default) up to 1.30, where the Helldiver starts
swimming. Press Apply (Tab) to use a new value. Without Mod Options Menu the
limit stays 0.20. Mod Options Menu is optional and installed separately:
https://github.com/CowboyBingus/ModOptionsMenu/releases/latest

Install
1. Close Helldivers 2.
2. Import Shallow-Water-Diving-v3.8.1.zip and Bingus-Shared-Loader-v18.zip into
   Arsenal or HD2MM. Replace any previous Shallow Water Diving or loader entry
   rather than enabling two copies.
3. Enable both packages. With Arsenal's default priority, place Bingus Shared
   Loader last; with first-mod priority, place it first.
4. Purge and Deploy, then start the game normally.

Requires Bingus Shared Loader v18: https://github.com/CowboyBingus/BingusSharedLoader/releases/latest
Supported: Steam build 25480438 / EXE 1.8.46015.0. Other builds are refused by
the mod's own checks.

Log: %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/ShallowWaterDiving.log
It is written when the game starts and shuts down and whenever the mod stops.

Uninstall with the game closed: disable Shallow Water Diving, then Purge and
Deploy. Keep the loader enabled if other mods require it.
