Shallow Water Diving — data-v2 gameplay candidate
Requires Bingus Shared Loader loader-v5 / API 1.
Supported Steam build 24826606 / EXE 1.8.45317.0.

Upgrading from data-v1: replace the Shallow Water Diving package. The existing
loader-v5 is sufficient. data-v2 waits through native initialization instead
of stopping permanently on a missing game pointer.

Close Helldivers 2. Import ShallowWaterDiving.zip and the updated
BingusSharedLoader.zip into Arsenal or HD2MM. Replace the previous loader
entry rather than enabling two copies. Enable both packages, then Purge and
Deploy. With Arsenal's default priority, place Bingus Shared Loader last.

Use the normal dive input. Shallow water should allow the airborne leap;
landing restores ordinary prone/water behavior. Ordinary prone input is unchanged.

This is an offline-tested candidate, not a gameplay-verified release.
The first-dive-frame callback timing must still be checked in-game.
The log is %LOCALAPPDATA%/ShallowWaterDiving.log.

Uninstall with the game closed: disable Shallow Water Diving, then Purge and
Deploy. Keep the loader enabled if other mods require it.
